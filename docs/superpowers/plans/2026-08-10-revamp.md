# Spongebob Repo Revamp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restructure the repo to the standard Go layout (library at root, CLI under `cmd/`), fix the `rand.Seed` deprecation, clean up the README, add basic CI, and wire up automated GoReleaser releases that publish a Homebrew formula to `calini/homebrew-tap`.

**Architecture:** No new runtime behavior — this is a structural/infra revamp of an existing, working library (`Text(string) string`). Five tasks: (1) move library to root + CLI to `cmd/spongebob` + remove the deprecated `rand.Seed` call + bump `go.mod`, (2) rewrite `README.md`, (3) add `.github/workflows/ci.yml`, (4) add `.goreleaser.yaml` + `.github/workflows/release.yml`, (5) remove the hand-written `spongebob.rb` from `calini/homebrew-tap` so GoReleaser owns it from the next tag.

**Tech Stack:** Go 1.21+, GitHub Actions, GoReleaser v2, Homebrew.

## Global Constraints

- Module path stays `github.com/calini/spongebob`; library package stays named `spongebob`.
- `go.mod` go directive: `go 1.21` (floor for `math/rand` global auto-seeding).
- Keep the README joke line verbatim: `It uses _CUTTING EDGE_ technology like *MARKOV CHAINS™* to generate _REALISTIC_ SPonGeBoBⓇ text.️`
- No `--version` flag or build-time version injection (out of scope per spec).
- No golangci-lint config or coverage gate — CI is intentionally lean (per spec, explicit choice over `governor`'s fuller CI).
- Release repo: GitHub `calini/spongebob`, owner `calini`, name `spongebob`. Homebrew tap repo: `calini/homebrew-tap`. Push token: `HOMEBREW_TAP_GITHUB_TOKEN` (already set as a repo secret on `calini/spongebob`).
- Spec: `docs/superpowers/specs/2026-08-10-revamp-design.md`.

- [ ] **Step 2: Rewrite `text.go` to drop the deprecated `rand.Seed` call**

Replace the full contents of `text.go` with:

```go
// Package spongebob converts normal text into sPonGeBOb tExT.
package spongebob

import (
	"bytes"
	"math/rand"
	"unicode"
)

// Text transforms a normal string into A spOnGEbOb sTrINg.
func Text(str string) string {
	var result bytes.Buffer
	upper := false

	for _, c := range str {
		if unicode.IsLetter(rune(c)) {
			// instead of flipping a coin every time,
			// we create a poor man's Markov chain
			if rand.Float32() < 0.6 {
				upper = !upper
			}

			if upper {
				c = unicode.ToUpper(rune(c))
			} else {
				c = unicode.ToLower(rune(c))
			}
		}
		result.WriteRune(c)
	}

	return result.String()
}
```

This removes the `init()`/`rand.Seed(time.Now().UTC().UnixNano())` block and the now-unused `time` import. As of Go 1.20, the global `math/rand` source auto-seeds, so there's nothing to replace the call with.

`text_test.go` needs no content changes — only its location moved. Leave it as:

```go
package spongebob

import (
	"strings"
	"testing"
)

// TestText checks that transformation is happening without ruining context
func TestText(t *testing.T) {
	input := "Hello world!"
	result := Text(input)

	if !strings.EqualFold(input, result) {
		t.Errorf("Should have same content except capitalisation: \"%s\" - \"%s\"", input, result)
	}
}
```

### Task 4: Add GoReleaser config and release workflow

**Files:**
- Create: `.goreleaser.yaml`
- Create: `.github/workflows/release.yml`

**Interfaces:**
- Consumes: `cmd/spongebob` build target from Task 1; `HOMEBREW_TAP_GITHUB_TOKEN` and `GITHUB_TOKEN` secrets (already present on `calini/spongebob`).
- Produces: on a `v*` tag push, GitHub release artifacts + an auto-generated `spongebob.rb` commit to `calini/homebrew-tap` (this replaces the hand-written formula removed in Task 5).

- [ ] **Step 1: Create `.goreleaser.yaml`**

```yaml
version: 2

project_name: spongebob

before:
  hooks:
    - go mod tidy

builds:
  - main: ./cmd/spongebob
    binary: spongebob
    env:
      - CGO_ENABLED=0
    ldflags:
      - -s -w
    goos:
      - linux
      - darwin
      - windows
    goarch:
      - amd64
      - arm64

archives:
  - formats: [tar.gz]
    format_overrides:
      - goos: windows
        formats: [zip]

checksum:
  name_template: "checksums.txt"

changelog:
  sort: asc
  filters:
    exclude:
      - "^test:"
      - "^chore:"

release:
  github:
    owner: calini
    name: spongebob

brews:
  - name: spongebob
    repository:
      owner: calini
      name: homebrew-tap
      token: "{{ .Env.HOMEBREW_TAP_GITHUB_TOKEN }}"
    directory: .
    homepage: "https://github.com/calini/spongebob"
    description: "CLI for writing SPonGeBob TeXT"
    license: "MIT"
    commit_author:
      name: Calin Ilie
      email: calin@ilie.io
    install: |
      bin.install "spongebob"
    test: |
      system "#{bin}/spongebob", "test"
```

- [ ] **Step 2: Create `.github/workflows/release.yml`**

```yaml
name: release

on:
  push:
    tags:
      - "v*"

permissions:
  contents: write

jobs:
  goreleaser:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - uses: actions/setup-go@v5
        with:
          go-version-file: go.mod

      - uses: goreleaser/goreleaser-action@v7
        with:
          distribution: goreleaser
          version: "~> v2"
          args: release --clean
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          HOMEBREW_TAP_GITHUB_TOKEN: ${{ secrets.HOMEBREW_TAP_GITHUB_TOKEN }}
```
